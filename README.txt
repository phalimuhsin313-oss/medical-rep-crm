# نظام المندوب الطبي CRM Mobile - نسخة PWA

هذه النسخة مخصصة حتى تشتغل مثل تطبيق مثبت على الهاتف.

## الملفات
- index.html: التطبيق الرئيسي
- manifest.json: ملف تعريف التطبيق للتثبيت
- service-worker.js: ملف تشغيل Offline
- icons/: أيقونات التطبيق

## طريقة الاستخدام المختصرة
1. ارفع كل الملفات كما هي على GitHub Pages أو Netlify.
2. افتح الرابط من Google Chrome على الهاتف.
3. اضغط القائمة ⋮ ثم: إضافة إلى الشاشة الرئيسية.
4. افتح التطبيق من الأيقونة الجديدة.
5. استخدم Backup JSON بشكل دوري للاحتياط.

## التخزين
التطبيق يستخدم:
- LocalStorage للحفظ السريع.
- IndexedDB كحفظ أقوى داخل المتصفح.
- Backup JSON للتأمين اليدوي.
